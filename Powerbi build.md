# 16 - Power BI: the CLV report (`.pbix`)

## FASTEST ROUTE: open the ready-made project (`16_powerbi_project/CLV_Report.pbip`)
A `.pbix` is a proprietary binary that only Power BI Desktop can write, so it can't be generated in this chat. The closest thing is a
**Power BI Project (PBIP)**: the same report as readable text files (model in TMDL, 3 report pages). Steps:
1. Power BI Desktop > File > Options > Preview features > tick **Power BI Project (.pbip) save option** and **Store semantic model using TMDL format**; restart.
2. Copy `data/processed/` (transactions_clean.csv, customers_clean.csv, products_clean.csv, clv_predictions.csv) to e.g. `C:\clv\data\processed\`.
3. File > Open > `CLV_Report.pbip`. Home > Transform data > Manage parameters > set **DataFolder** to your folder (end with a backslash) > Close & Apply.
4. **File > Save as > `CLV_Report.pbix`** - that is your .pbix.
5. View > Themes > Browse for themes > `16_powerbi_theme.json` (optional).
The project was generated by script and has not been opened in Desktop here. If Desktop reports a model/visual error, use the manual steps below
(they build the identical model, measures and pages in ~20 minutes).

# Manual build (also the reference for what the PBIP contains)

## 1. Get data  (Home > Get data > Text/CSV, or MySQL)
Load these from `data/processed/`: `clv_predictions.csv`, `transactions_clean.csv`, `customers_clean.csv`, `products_clean.csv`.
(MySQL option: Get data > MySQL database > `clv_db`, tables `fact_transactions`, `dim_customer`, `dim_product`, view `vw_clv_dashboard`.)

Power Query M (Transform data > Advanced Editor) for the predictions table:
```m
let
    Source   = Csv.Document(File.Contents("C:\clv\data\processed\clv_predictions.csv"),
                 [Delimiter=",", Encoding=65001, QuoteStyle=QuoteStyle.Csv]),
    Promoted = Table.PromoteHeaders(Source, [PromoteAllScalars=true]),
    Typed    = Table.TransformColumnTypes(Promoted, {
                 {"customer_id", Int64.Type}, {"recency_days", Int64.Type}, {"frequency", Int64.Type},
                 {"monetary", type number}, {"aov", type number}, {"predicted_clv_6m", type number},
                 {"total_clv", type number}, {"age", Int64.Type}, {"signup_date", type date}}),
    AgeBand  = Table.AddColumn(Typed, "age_band", each
                 if [age] < 25 then "18-24" else if [age] < 35 then "25-34" else if [age] < 45 then "35-44"
                 else if [age] < 55 then "45-54" else "55+", type text)
in AgeBand
```
Transactions table: set `order_date` to Date, `line_revenue`/`unit_price` to Decimal.

## 2. Model (Model view)
Star schema: `customers_clean[customer_id]` 1 -> * `transactions_clean[customer_id]`, `products_clean[product_id]` 1 -> * `transactions_clean[product_id]`,
`clv_predictions[customer_id]` 1 -> 1 `customers_clean[customer_id]`, `Date[Date]` 1 -> * `transactions_clean[order_date]`.
Date table (Modeling > New table):
```dax
Date = ADDCOLUMNS(CALENDAR(DATE(2024,1,1), DATE(2025,12,31)),
    "Year", YEAR([Date]), "MonthNo", MONTH([Date]), "Month", FORMAT([Date], "MMM yy"),
    "YearMonth", FORMAT([Date], "YYYY-MM"))
```
Mark as date table (Table tools > Mark as date table). Sort `Month` by `MonthNo`.

## 3. DAX measures (create a `_Measures` table: Enter data > blank > rename)
```dax
Total Revenue      = SUM(transactions_clean[line_revenue])
Orders             = DISTINCTCOUNT(transactions_clean[order_id])
Customers          = DISTINCTCOUNT(clv_predictions[customer_id])
AOV                = DIVIDE([Total Revenue], [Orders])
Predicted CLV 6M   = SUM(clv_predictions[predicted_clv_6m])
Avg Predicted CLV  = DIVIDE([Predicted CLV 6M], [Customers])
Total CLV          = SUM(clv_predictions[total_clv])
Repeat Rate        = DIVIDE(CALCULATE([Customers], clv_predictions[frequency] > 1), [Customers])
Platinum Share     = DIVIDE(CALCULATE([Predicted CLV 6M], clv_predictions[clv_segment] = "Platinum"), [Predicted CLV 6M])
At-Risk High Value = CALCULATE([Customers], clv_predictions[rfm_segment] = "At Risk",
                                clv_predictions[clv_segment] IN {"Platinum","Gold"})

Revenue PM  = CALCULATE([Total Revenue], DATEADD('Date'[Date], -1, MONTH))
Revenue MoM % = DIVIDE([Total Revenue] - [Revenue PM], [Revenue PM])
Revenue YTD = TOTALYTD([Total Revenue], 'Date'[Date])
Revenue Rolling 3M = CALCULATE([Total Revenue], DATESINPERIOD('Date'[Date], MAX('Date'[Date]), -3, MONTH))

Cumulative Rev % (Pareto) =
VAR cur = [Predicted CLV 6M]
VAR t   = CALCULATE([Predicted CLV 6M], ALLSELECTED(clv_predictions[customer_id]))
RETURN DIVIDE(
   SUMX(FILTER(ALLSELECTED(clv_predictions[customer_id]), [Predicted CLV 6M] >= cur), [Predicted CLV 6M]), t)

New Customers = CALCULATE(DISTINCTCOUNT(clv_predictions[customer_id]),
                          USERELATIONSHIP('Date'[Date], clv_predictions[signup_date]))   -- needs inactive rel signup_date
Segment Label = SELECTEDVALUE(clv_predictions[clv_segment], "All segments")
```

## 4. Report pages
| Page | Visuals |
|---|---|
| **1 Executive** | 5 KPI cards (Total Revenue, Customers, AOV, Repeat Rate, Predicted CLV 6M); line chart Revenue by `Date[YearMonth]` + MoM %; donut Customers by `clv_segment`; bar Avg Predicted CLV by `acquisition_channel`; slicers: country, year |
| **2 Segmentation** | Treemap `rfm_segment` by Customers; clustered column Predicted CLV by `clv_segment`; scatter Frequency (x) vs Monetary (y), size = Predicted CLV, legend = `clv_segment`; matrix RFM segment x CLV segment (count) |
| **3 Customers** | Table: customer_id, country, recency, frequency, monetary, predicted CLV, segment (conditional data bars); Top N filter 20 by Predicted CLV; drill-through from Executive |
| **4 Model** | Import `model_metrics.csv`; table of MAE / RMSE / R2 / Spearman; image of `reports/figures/07_model_diagnostics.png` |

Extras: bookmarks for "Platinum focus"; tooltip page with customer profile; conditional formatting on recency (red > 180).
